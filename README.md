# Python Calculator 🧮

A simple command-line calculator built with Python. This beginner project helps me practice user input, conditional statements, and arithmetic operations.

## Features

- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)

## Requirements

- Python 3 installed on your computer

## How to Run

1. Download or clone this repository.
2. Open a terminal in the project folder.
3. Run:

   ```bash
   python calculator.py
   ```

4. Enter the first number, choose an operator, and enter the second number.

> If your Python file has a different name, replace `calculator.py` with your filename.

## Example

```text
Enter first number: 10
Enter operator (+, -, *, /): +
Enter second number: 5

Result: 15
```
